# QuickCart – Advanced JavaScript Practical Assignment

## About the Project

QuickCart is an e-commerce JavaScript project developed as part of an Advanced JavaScript Practical Assignment.

It demonstrates JavaScript concepts through product management, shopping cart calculations, JSON handling, asynchronous operations, performance optimization, and order processing.

## Technologies Used

- JavaScript
- Node.js
- HTML and CSS (where applicable)

## Concepts Covered

### Part A – Objects and Classes
- Constructor functions
- Prototypes
- ES6 classes
- Inheritance
- Arrow functions
- Destructuring
- Rest and spread operators

### Part B – Array Methods
- map()
- filter()
- reduce()
- forEach()
- Map and Set
- Object.freeze()
- Object.seal()

### Part C – JSON Handling
- JSON.stringify()
- JSON.parse()
- Order calculations
- Error handling

### Part D – Asynchronous JavaScript
- Promises
- then() and catch()
- async and await
- Promise.all()
- setTimeout()

### Part E – Performance Optimization
- Product searching
- Memoization
- Debouncing

### Part F – Integration
- Product management
- Cart calculations
- JSON order creation
- Asynchronous order confirmation

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the required JavaScript file using Node.js.

Example:

```bash
node part-f-integration/quickcart.js
```
